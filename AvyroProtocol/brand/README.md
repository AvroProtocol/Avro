# AVYRO brand assets

This folder contains the primary AVYRO visual references included with the rebranded source pack.

- `avyro-identity-board.png` — visual identity reference board
- `avyro-mark-black.png` — black mark for light backgrounds
- `avyro-mark-white.png` — white mark for dark backgrounds
- `avyro-app-icon.png` — square app/social icon

The product UI uses a monochrome black/white system with a persistent light/dark theme toggle.
