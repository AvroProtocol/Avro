# AVRO brand assets

This folder contains the primary AVRO visual references included with the rebranded source pack.

- `avro-identity-board.png` — visual identity reference board
- `avro-mark-black.png` — black mark for light backgrounds
- `avro-mark-white.png` — white mark for dark backgrounds
- `avro-app-icon.png` — square app/social icon

The product UI uses a monochrome black/white system with a persistent light/dark theme toggle.
